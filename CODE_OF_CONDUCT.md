# Code of conduct

Brainmatter follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep criticism about the work, not the person. Harassment, insults, and publishing someone's private information are not welcome here, in issues, pull requests or anywhere else the project lives.

If something happens that should not, tell the maintainer privately through [their GitHub profile](https://github.com/Kiritosky), or use GitHub's **Report content**. Reports are handled confidentially. The maintainer may edit or remove comments, and block people who keep breaking these rules.
